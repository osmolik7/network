# Introducción

En este curso de fundamentos de redes para ingenieros se pretende comprender como funcionan las redes para la conexiones que se realizan desde nuestras aplicaciones. 

Como se conectan internamente y cual es el funcionamiento que generalmente no entendemos como ingenieros de sistemas. 

Todas las conexiones a APIS o entre FrontEnd y BackEnd hacen uso de las redes.
