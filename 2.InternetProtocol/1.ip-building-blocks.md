# Entendiendo el IP protocolo

- Esta en la capa 3 de Red
- Puede ser automatica o estatica
- Tiene dos partes la de red y la de host .________.___ 
- Se divide en 4 bytes conformados cada uno por 8 bites 11000000.10101000.00000001.00000010 = 192.18.1.2. 
- Se aumenta de 2 en 2 de izquierda a derecha y las posibles combinacioes son 2^n

## Anatomía del paquete IP

- Se agrega el encabezado de ip a los datos que por lo general ocupan 20 bytes 
- LA seccion de datos puede ser de hasta 65536 bytes porque el tamaño de la data máximo es de 16 bits
- Maximun Transmision Unit (MTU) es 1500 bytes

## ICMP

- Es el protocolo que permite al protocolo IP enviar mensajes 
- Ping y Tracert usan este protocolo para el envio de mensajes
