# Modelo OSI (Open System Interconnection)

Todo ingeniero en sistemas debería saber el modelo OSI y entender las 7 capas efectivamente. Adicional es importante saber en que capa se encuentra nuestra aplicación. 


## Por qué se necesita un modelo abierto de interconección? 

- Aplicaciones agonosticas: No importa desde donde estemos realizando la petición (wifi, network, lte, etc)
- Administradores de equipos de red
- Innovación desacoplada: Cada capa se puede mejorar por separado sin afectar el resto del modelo. 

## 7 Capas
- Capa 7 - Aplicacion - HTTP/FTP/GRPC
- Capa 6 - Pesentación - Enconding, Serialización
- Capa 5 - Sesión - Establecer conexión, TLS
- Capa 4 - Transporte - UDP/TCP
- Capa 3 - Red - IP
- Capa 2 - Data Link - Frames, Dirección Mac
- capa 1 - Fisica - Electric signals, fiber or radio waves
