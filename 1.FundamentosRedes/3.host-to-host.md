# Host to Host Communication 

- Usualmente se realiza desde una peticion a un host mediante (RPC-remote procedure call)
- Cada tarjeta de red tiene un unico identificador (MAC-Media access control address)
- Usando la mac se debe enviar el mensaje a todos los dispositivos de la red hasta que uno verifique que es el destino y acepte el mensaje. 
- Para realizar un enrutamiento escalable se necesita de IP porque presenta un diseño de tipo jerarquia para poder llegar de manera eficiente al equipo destino.
- Se sigue necesitando de la direccion MAC pero llegar a esta es mas eficiente. 
- La IP se divide en dos partes la red y el host todo esto identificado por la mascara de red /24 por ejemplo.

# Como se sabe a que aplicación va el mensaje? 

- Se hace uso del puerto que tien relación con un proceso en el CPU
- Se puede neivar un HTTP request en el puerto 80, DNS peticion en el puerto 53 y para SSH peticiones corren en el puerto 22 todos en la misma computadora.
