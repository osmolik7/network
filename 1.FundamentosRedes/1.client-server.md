# Client - Server Architecture

El concepto es sencillo, se separa la arquitectura entre un cliente y un servidor donde se ejecutaran tareas complejas y se recibira una respuesta en un dispositivo que tiene menos recursos comunmente.

Se llaman desde el cliente procedimiento (remote procedure call)

# Beneficios
- Servidores con hardware robusto 
- Clientes con hardware ligero
- Clientes aun pueden realizar tareas sencillas
- Clientes no requieren dependencias
- Se necesita un modelo de comunicación 

El problema ahora es el modelo de comunicación y para esto se necesita un estandar.
